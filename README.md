# SkillBridge — Career & Recruitment Platform

SkillBridge is a modern career and recruitment web application built with React, Vite, Node.js, Express, and MongoDB Atlas.

---

## Architecture Overview

SkillBridge is configured for **Single-Service Render Deployment**:
- **Single Public URL & Service**: The Node.js + Express backend serves both the compiled React frontend static bundle (`dist/`) and all `/api/*` REST endpoints from a single Render Web Service.
- **SPA Client Routing**: All non-API frontend routes (e.g. `/`, `/login`, `/student/dashboard`, `/recruiter/dashboard`, `/jobs`) fall back to React Router (`index.html`), preventing 404 errors on browser refresh.
- **Isolated API Space**: Unknown `/api/*` endpoints strictly return structured JSON 404 responses (`{ success: false, code: 'NOT_FOUND' }`) and never fall back to HTML.
- **Database**: External MongoDB Atlas database with Mongoose ODM and automatic failover handling.
- **Zero CORS Overhead**: In production, the frontend uses relative `/api` requests on the same origin domain.

## Local Development Setup

### Prerequisites
- Node.js >= 20.0.0
- npm >= 10.0.0
- MongoDB Atlas cluster or local MongoDB instance

### 1. Clone & Install Dependencies

```bash
git clone https://github.com/your-username/SkillBridge.git
cd SkillBridge

# Install frontend dependencies
npm install

# Install backend dependencies
cd server
npm install
cd ..
```

### 2. Configure Environment Variables

**Frontend (`.env` in repository root):**
```env
# Optional in dev; defaults to http://localhost:5000/api
VITE_API_URL=http://localhost:5000/api
```

**Backend (`server/.env`):**
```env
PORT=5000
NODE_ENV=development
MONGODB_URI=mongodb+srv://<username>:<password>@<cluster>.mongodb.net/skillbridge?retryWrites=true&w=majority
JWT_SECRET=your_super_secret_dev_key_at_least_32_characters_long
JWT_EXPIRES_IN=7d

# Optional integrations
RESEND_API_KEY=
EMAIL_FROM=SkillBridge <notifications@skillbridge.io>
CLOUDINARY_CLOUD_NAME=
CLOUDINARY_API_KEY=
CLOUDINARY_API_SECRET=
```

### 3. Run Locally

Open two terminal windows:

**Terminal 1 — Backend:**
```bash
cd server
npm run dev
# Server runs on http://localhost:5000
```

**Terminal 2 — Frontend:**
```bash
npm run dev
# Vite runs on http://localhost:5173 with proxy / API client pointing to :5000
```

## Single-Service Render Deployment

SkillBridge includes a production-ready `render.yaml` blueprint that builds the frontend and runs the unified Express server inside **one Render Web Service**.

### 1. Blueprint Configuration (`render.yaml`)

- **Service Type**: `web`
- **Service Name**: `skillbridge-frontend`
- **Runtime**: `node`
- **Root Directory**: `.`
- **Build Command**:
  ```bash
  npm install && npm run build && cd server && npm install
  ```
- **Start Command**:
  ```bash
  cd server && npm start
  ```
- **Health Check Path**: `/api/health`

### 2. Deploy via Render Blueprint

1. Push your changes to your GitHub repository.
2. In the [Render Dashboard](https://dashboard.render.com), click **New +** -> **Blueprint**.
3. Select your SkillBridge GitHub repository.
4. Render will detect `render.yaml` and configure the single Web Service.
5. In the Environment Variables settings for `skillbridge-frontend`, supply your production values:
   - `MONGODB_URI`: Your MongoDB Atlas connection string (`mongodb+srv://...`).
   - `RESEND_API_KEY` *(optional)*: For transactional emails.
   - `CLOUDINARY_CLOUD_NAME`, `CLOUDINARY_API_KEY`, `CLOUDINARY_API_SECRET` *(optional)*: For file uploads.
6. Click **Apply Blueprint** to initiate the deployment.
